# Engenharia de Dados com Azure Databricks

Este repositório reúne exemplos práticos de engenharia de dados, organizados por tema. Cada pasta contém um notebook e um guia com o objetivo e os passos para executá-lo.

## Conteúdo

| Pasta | Tema |
|---|---|
| [01-modelagem-dados](01-modelagem-dados/) | Modelagem dimensional, SCD Tipo 2 e histórico Delta |
| [02-ingestao-unity-catalog](02-ingestao-unity-catalog/) | Ingestão em lote e incremental |
| [03-transformacao-dados](03-transformacao-dados/) | Limpeza, tipagem e transformação de dados |
| [04-qualidade-dados](04-qualidade-dados/) | Validações e qualidade de dados |
| [05-pipelines-dados](05-pipelines-dados/) | Pipeline medalhão e processamento de reservas |
| [06-lakeflow-jobs](06-lakeflow-jobs/) | Orquestração de processamento de eventos de telecomunicações |
| [07-ciclo-desenvolvimento](07-ciclo-desenvolvimento/) | Testes, implantação e automação |
| [08-monitoramento-otimizacao](08-monitoramento-otimizacao/) | Diagnóstico e otimização de workloads Spark |

## Como começar

1. Escolha um tema e abra o README da pasta.
2. Importe o notebook daquela pasta para seu workspace Azure Databricks.
3. Configure o compute e as permissões indicadas no guia.
4. Execute as etapas do notebook na ordem apresentada.

Alguns exemplos criam recursos no workspace e podem gerar custos de computação.
