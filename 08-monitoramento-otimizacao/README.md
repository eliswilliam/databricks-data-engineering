## Objetivo

Observe desequilíbrio de dados e shuffle excessivo no Spark UI e aplique ajustes para melhorar o processamento.

## Notebook

[13-monitor-troubleshoot-optimize-workloads-azure-databricks.ipynb](13-monitor-troubleshoot-optimize-workloads-azure-databricks.ipynb)

## Requisitos

- Workspace Azure Databricks com permissão para criar compute clássico.
- Compute: Cluster clássico sem Photon.

## Execução

1. Importe o arquivo .ipynb para uma pasta no seu workspace Azure Databricks.
2. Selecione o compute indicado em **Requisitos**.
3. Leia as instruções de cada seção e execute as células na ordem do notebook.
4. Confira as tabelas, métricas ou resultados produzidos ao final.
