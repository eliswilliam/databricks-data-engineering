# Limpeza e transformação de dados

<p align="center"><img src="../assets/azure-databricks.svg" alt="Azure Databricks — engenharia de dados" width="520"></p>

## Objetivo

Explore e prepare dados imobiliários: analise qualidade, defina tipos, trate nulos e duplicatas, combine tabelas e reorganize estatísticas.

## Notebook

[08-cleanse-transform-load-data-into-unity-catalog.ipynb](08-cleanse-transform-load-data-into-unity-catalog.ipynb)

## Requisitos

- Workspace Azure Databricks com Unity Catalog.
- Compute: Serverless.

## Execução

1. Importe o arquivo .ipynb para uma pasta no seu workspace Azure Databricks.
2. Selecione o compute indicado em **Requisitos**.
3. Leia as instruções de cada seção e execute as células na ordem do notebook.
4. Confira as tabelas, métricas ou resultados produzidos ao final.
