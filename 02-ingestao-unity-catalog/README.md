# Ingestão de dados

## Objetivo

Carregue arquivos para tabelas Delta usando DataFrames PySpark, COPY INTO, CTAS e Auto Loader.

## Notebook

[07-ingest-data-into-unity-catalog.ipynb](07-ingest-data-into-unity-catalog.ipynb)

## Requisitos

- Workspace Azure Databricks com Unity Catalog e permissão para criar catálogo e volume.
- Compute: Serverless.

## Execução

1. Importe o arquivo .ipynb para uma pasta no seu workspace Azure Databricks.
2. Selecione o compute indicado em **Requisitos**.
3. Leia as instruções de cada seção e execute as células na ordem do notebook.
4. Confira as tabelas, métricas ou resultados produzidos ao final.
