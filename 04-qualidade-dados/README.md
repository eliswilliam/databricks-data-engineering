# Qualidade de dados

<p align="center"><img src="../assets/azure-databricks.svg" alt="Azure Databricks — engenharia de dados" width="520"></p>

## Objetivo

Valide dados de sinistros em uma pipeline, aplicando expectativas, conversões de tipos e tratamento de alterações de esquema.

## Notebook

[09-implement-manage-data-quality-constraints-unity-catalog.ipynb](09-implement-manage-data-quality-constraints-unity-catalog.ipynb)

## Requisitos

- Workspace Azure Databricks com Unity Catalog e permissão para criar pipelines.
- Compute: Serverless.

## Execução

1. Importe o arquivo .ipynb para uma pasta no seu workspace Azure Databricks.
2. Selecione o compute indicado em **Requisitos**.
3. Leia as instruções de cada seção e execute as células na ordem do notebook.
4. Confira as tabelas, métricas ou resultados produzidos ao final.
