# Modelagem de dados

## Objetivo

Modele dados financeiros com dimensão de clientes SCD Tipo 2, fatos de transações e recursos Delta para auditoria e consulta histórica.

## Notebook

[06-design-implement-data-modeling-unity-catalog.ipynb](06-design-implement-data-modeling-unity-catalog.ipynb)

## Requisitos

- Workspace Azure Databricks com Unity Catalog e permissão para criar catálogo.
- Compute: Serverless.

## Execução

1. Importe o arquivo .ipynb para uma pasta no seu workspace Azure Databricks.
2. Selecione o compute indicado em **Requisitos**.
3. Leia as instruções de cada seção e execute as células na ordem do notebook.
4. Confira as tabelas, métricas ou resultados produzidos ao final.
